# CosmicYonder
Cosmic Yonder est un jeu de type Roguelike.
Pour demarer une partie selectionner nouvelle partie.
La fonctionnalité restore partie de fonctionne malheureusement pas par faute de temps.
A n'importe quel moment dans le jeu, le menu est accessible il suffit de taper 'm'.
Pour sauvegarder il faut taper 'q'.


Pour quitter le jeu il faut d'abord acceder au menu avec la touche m puis quitter avec q.
